## 🚀 Projeto II

Nesse projeto, implementei a cinemática de um robô diferencial em Python e de um Ackermann em C++. Os nós recebem comandos de velocidade e calculam as velocidades das rodas e, no Ackermann, os ângulos de direção.

Também utilizei parâmetros em arquivos YAML e um launch para escolher qual modelo iniciar. As mensagens personalizadas ficaram separadas em um pacote de interfaces, e a maioria dos testes foi feita com `ros2 topic echo`.

👉 [Clique aqui](https://github.com/eduardohbb/robotics_ros_eduardo_bonfim/tree/projeto-II/ros_ws) para acessar o README do Projeto II.
